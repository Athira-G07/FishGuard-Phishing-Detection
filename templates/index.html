About This Project

This project is a machine-learning-based phishing website detection system developed using Python, Flask and Random Forest classification. The system analyzes website-related features to identify potentially malicious websites.

⚠️ Important Notice

PhishGuard is a machine-learning-based detection tool intended for educational and informational purposes. A prediction does not guarantee that a website is safe or malicious. Always use caution when visiting unfamiliar websites and avoid sharing sensitive information.
